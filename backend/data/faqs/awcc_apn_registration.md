## AWCC APN / internet settings and SIM registration

- Auto settings (recommended): Send `1` via SMS to `2009` to receive GPRS/APN settings. Use PIN `1234`. If still failing, call `152` support.
- Manual APN (fallback): Some directories list APN as `internet`; verify with AWCC if auto-config fails.
- SIM registration: Visit an AWCC Brand Shop or authorized outlet with ID (Tazkira/passport). Rules can change; confirm with AWCC support at `152`.
