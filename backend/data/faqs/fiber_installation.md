## Fiber installation and troubleshooting

- Standard install window is 3 business days; technicians call 30 minutes before arrival.
- ONT lights: PON should be solid green; LOS flashing red indicates fiber break—raise a ticket immediately.
- Wi-Fi SSID and default password are printed under the ONT; advise customers to change after install.
- If speed tests show <80% of plan, test via Ethernet before escalating.
- Missed appointments are rescheduled within 24 hours with priority slots.
